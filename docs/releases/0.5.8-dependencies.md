# NimbusDNS 0.5.8 dependency review

Checked on 2026-09-06 against an individual crates.io API request for each of 300 distinct registry packages in Cargo.lock (including target-specific and transitive dependencies). “Latest” means the latest non-prerelease version reported by crates.io, not only the version allowed by the previous manifest.

All 37 direct dependencies resolve to their latest stable release. Argon2 was migrated from 0.5.3 to 0.6.0 and password-hash from 0.5.0 to 0.6.1. The unused direct rand_core dependency was removed; its transitive version is 0.10.1. Existing 0.5.7 password hashes have a compatibility regression test.

Transitive constraints are retained rather than forcing incompatible major versions. For example, axum 0.8.9 pins matchit exactly to 0.8.4, even though matchit 0.9.2 exists. reqwest still requires a separate tower-http 0.6 series alongside our direct 0.7.1 dependency. Multiple versions in the table are intentional dependency graph entries, not missed direct upgrades.
