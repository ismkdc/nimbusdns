# NimbusDNS 0.5.10

Reliability fixes for the DNS and DHCP listeners, and a DNS cache that keeps working once it fills up.

**DNS listeners no longer stop on a socket error.** Previously a single failed `recv_from` on the UDP socket, or a failed `accept` on the TCP listener (for example EMFILE when the process runs out of file descriptors), ended the listener loop. The process kept running, so container restart policies never kicked in, while every DNS query on that transport went unanswered. Both loops now log the error, back off for 50 ms and keep serving.

**DHCP receive errors no longer spin the CPU.** A persistent receive error made the DHCP loop retry immediately in a tight loop. It now logs a warning and backs off for 50 ms between attempts.

**Expired cache entries are reclaimed.** Expired entries used to be removed only when the same name was looked up again, so a busy cache filled up with dead entries, and the eviction that followed dropped live answers instead. Expired entries are now swept every 60 seconds and reclaimed before any live entry is evicted, which keeps the hit rate stable over long uptimes.

No configuration, database or API changes; upgrading is a drop-in image replacement.
