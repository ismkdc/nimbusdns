# NimbusDNS 0.5.11

Dependency maintenance release. All direct Rust dependencies are updated to their latest releases:

| Crate | From | To |
|-------|------|----|
| tokio | 1.54.0 | 1.54.1 |
| rusqlite | 0.40.2 | 0.41.1 |
| parking_lot | 0.12.5 | 0.13.0 |
| uuid | 1.28.0 | 1.29.0 |
| signal-hook | 0.4.5 | 0.4.6 |

`rusqlite` 0.41 and `parking_lot` 0.13 are new minor versions of 0.x crates (semver-breaking in principle); neither needed a code change. `rusqlite` 0.41 moves to `libsqlite3-sys` 0.39, which bundles a newer SQLite. SQLite's on-disk format is backward compatible, so existing query-log and settings databases open unchanged.

Cargo.lock is refreshed as well (45 packages, including aws-lc-rs 1.19.0, rustls-webpki 0.103.16 and webpki-root-certs 1.0.11). The full test suite (202 tests) and clippy with `-D warnings` pass. The IEEE OUI database is the 2026-11-01 snapshot.

Existing `nimbus.toml` files, databases and DHCP leases are used as-is; upgrading is a drop-in image replacement.
